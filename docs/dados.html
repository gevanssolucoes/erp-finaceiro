Conhecer o Gevans Gestor

Envie a planilha, receba as telas prontas

Para quem já tem orçamento e realizado em Excel e quer os relatórios do Gevans Gestor sem lançar nada no sistema. A planilha é lida aqui no seu navegador e não é enviada para nenhum servidor.

Passo 1

Baixe o modelo

Uma aba com os lançamentos (orçado e realizado) e outra, opcional, com as premissas de pagamento de cada conta. Pode usar a sua própria base também, em Excel, CSV, PDF ou link de API: no passo 3 você diz qual coluna é qual.

Passo 2

Envie a base

Buscar de um link de API

Banco SQL (PostgreSQL, MySQL, SQL Server) e APIs que não liberam o navegador: use a tela Conexões de dados no Gevans Gestor.

Confira as colunas
